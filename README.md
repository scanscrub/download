# ScanScrub — downloads

**ScanScrub** removes patient identifiers from medical images — DICOM headers **and** text
burned into the pixels (X-ray, ultrasound, scanned and exported images) — entirely on your
computer. Website: https://scanscrub.pages.dev

## Download
👉 **[Latest release](https://github.com/scanscrub/download/releases/latest)** — Windows 10/11 (64-bit)

- `ScanScrub-Setup-x.y.z.exe` — installer (recommended, no admin rights needed)
- `ScanScrub-x.y.z-win64.zip` — portable version (unzip and run `ScanScrub.exe`)
- `.sha256` files — checksums to verify your download

Free for up to 50 images per batch. Pro and Lab licences remove the limit.

## Supported files
DICOM (uncompressed, JPEG, JPEG-LS, JPEG 2000, RLE), JPEG, PNG, TIFF, BMP, WebP, GIF,
JPEG 2000 and NIfTI (.nii / .nii.gz).

## Privacy
ScanScrub runs fully offline. It never uploads images, metadata or usage data.

## Important
ScanScrub is an assistive tool, not a medical device. Always review de-identified data
before sharing it.

Support: scanscrub.support@gmail.com · This repository only hosts releases; please email
